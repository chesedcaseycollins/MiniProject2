# Reflection: scify_jedaitoolkit

**Pattern.** Declining to zero. Bursts in 2017-04 (99 commits), 2018 and 2020-02 (76), then very little; from 2022 the series is mostly zeros. 29 authors. 7 gaps of 3+ months, the most of any project in this set. The longest is 2024-05 to 2025-06 (14 months).

**Longest gap.** The ten commits before it span almost two years (2022-10 to 2024-04): README updates and a file upload by gpapadis, two feature commits by Manos ("RCA without 2d float matrix"), a pom.xml update from an external account, and one merged example PR. That is already a project in wind-down. During the gap a single issue was opened ("Automation analysis", 2025-04-08) and never answered. The repository is now archived (read-only) on GitHub. The evidence makes the gap easy to interpret as abandonment by the maintainers.

**Recovery.** No. The only activity after the gap is a Dependabot PR bumping commons-lang3 from 3.4 to 3.18.0, merged by Paul Isaris on 2025-07-12. That is a security/dependency bump, not a restart, and it was merged by someone other than the earlier maintainer. Nothing has happened since.

**Current status.** By the six-month rule the project is "Active" because its last commit (2025-07-12) is after 2025-04-01, but that commit is a bot merge and the repo is archived. In practice it is dead.

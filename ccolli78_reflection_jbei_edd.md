# Reflection: jbei_edd

**Pattern.** Declining. The Experiment Data Depot had its peak in 2016-2017 at up to 204 commits/month, dropped sharply in late 2017, and has drifted down since to a few commits a month in 2023-2024. 28 authors, but two dominate (William Morrell and Mark Forrer), and by 2024 only Morrell is committing. There is no gap of 3+ months; the longest zero stretch is one month (2017-12).

**Longest gap.** With only one empty month there is nothing to explain, so the gap reason is recorded as "N/A active Project". For completeness: November 2017 commits are Python 3 and Docker work plus bug fixes by Forrer and Morrell, and January 2018 resumes with a run of bugfix PR merges (EDD-973, EDD-476, EDD-975, EDD-976, EDD-984) by Morrell. December 2017 looks like an ordinary holiday lull.

**Recovery.** Not applicable. The long-term story is a slow fade, not a gap and recovery.

**Current status.** Inactive. The last GitHub commit is 2024-12-11 ("Remove nested menus in docs"), more than six months before 2025-09-30. The last ten commits are all Morrell's maintenance: migration query fix, ICE integration test fix, duplicate-strain fix, removing the numpy dependency and the WebSocket container. Nothing suggests new development is planned.
